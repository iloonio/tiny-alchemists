# tiny-alchemists
DH2650 - Game Design project. 

## Dev Rules 
1. Keep Main functional at all times.
2. Create feature branches if you are working on a particular system, merge it into main when you are done.
3. Commit EVERYTHING that isn't included in the .gitignore. This is because Unity creates a bunch of additional files when you work in the editor, which are vital for a working branch (e.g. Package Dependencies, or .meta files)
4. Inform the group if you want to add a new package to the unity project

## General Rules
Making something new? Make a new scene in unity! Let's try to keep the project sanitary and isolate new additions features that way. Also, any "test" scenes you make should also be added in!!! They are super vital for developement :)
